# 업무 인수인계 — 이 PC의 모델 연결

업무 인수인계의 AI 보조는 기본으로 꺼져 있습니다. 켜도 이 PC의 `127.0.0.1`에만 연결합니다. 모델 파일은 설치 파일에 들어 있지 않습니다. 사용자가 따로 받습니다.

라이선스 준수를 보장하지 않습니다. 받는 모델의 이용 조건은 그 모델의 공식 문서에서 확인합니다.

## Ollama 설치

1. [Ollama](https://ollama.com/) 공식 사이트에서 Windows용 설치 파일을 받습니다.
2. 설치가 끝나면 Ollama가 이 PC에서 동작하는지 확인합니다. 기본 포트는 `11434`입니다.
3. 교육업무 런처의 업무 인수인계 화면에서 포트가 `11434`인지 확인합니다.

## 모델 받기

예시로 아래 두 가지를 쓸 수 있습니다. 다른 모델을 받아도 됩니다. 받은 모델의 이름과 이용 조건은 그 모델의 공식 문서를 봅니다.

```bat
ollama pull gemma3:4b
ollama pull exaone3.5:2.4b
```

받는 데 시간이 걸리고 디스크를 사용합니다. 작은 모델이 더 빨리 답합니다.

## 연결 확인

1. 업무 인수인계 화면에서 AI 보조를 켭니다.
2. 모델 목록을 누르거나, 목록이 없으면 모델 이름을 직접 입력합니다. 예: `gemma3:4b`
3. 연결 확인을 누릅니다. 응답하면 `응답함 · N초`만 보여 줍니다. 문서 내용은 이 확인에 보내지 않습니다.
4. 업무 폴더를 고르면 규칙으로 카드를 만든 뒤, 연결이 된 상태에서만 모델이 이름·할 일·기관·날짜를 제안합니다. 제안은 `AI 제안`으로 표시되고, 적용하거나 확인하기 전에는 업무 이름을 바꾸지 않습니다.

## 느릴 때

- 더 작은 모델을 받습니다. 예: `gemma3:4b` 대신 더 작은 크기.
- 한 번의 요청은 기본 90초를 넘기면 그 요청을 멈춥니다. 화면의 중지는 그때까지 모은 제안만 남깁니다.
- AI 보조를 끄면 규칙으로 만든 카드만 나옵니다. 모델이 없어도 시기와 기한 카드는 볼 수 있습니다.
- 다른 모델로 다시 정리는 규칙 결과는 두고, 아직 확인하지 않은 제안만 다시 받습니다.
