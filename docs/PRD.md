# PRD — 교육업무 런처 (EduLauncher)

기준일: 2026-09-21  
현재 설치 버전: `0.1.58-20260921`

## 한 줄

교육기관 직원이 Windows에서 자주 쓰는 사이트·프로그램·파일·폴더·공지를 작은 패널로 여는 **이 PC 전용** 트레이 런처.

## 사용자

학교·교육청 등 사무 직원. 계정 로그인 없이 자기 PC에 설치해 쓴다.

## 목표가 아닌 것

- 웹에서 프로그램을 실행하는 서비스가 아님
- 나이스·교육청 게시판 수집·자동 로그인 없음
- 공식 로고·파비콘 복사 없음
- PowerToys / Raycast / Alfred / Flow / 시작 메뉴 레이아웃 복제 없음
- 클라우드 동기화 없음

## 핵심 동작

| 항목 | 내용 |
|---|---|
| 상주 | 시스템 트레이. 창을 닫으면 종료가 아니라 숨김 |
| 열기 | 트레이 클릭 또는 `Ctrl+Alt+E` |
| 패널 | 440×650, 리사이즈 없음 |
| 바로가기 | 사이트 / 프로그램 / 파일 / 폴더 / 업무도구. 처음 설치에는 사이트·프로그램·파일·폴더가 비어 있음. 업무도구는 Network·CCTV·주소 무늬. 컴퓨터도구·업무자료는 앱에 있음. 이 PC에서 넣고 Pack으로 나눔 |
| Pack | `.edupack`·JSON. 공지 Pack과 바로가기 Pack |
| 끌어놓기 | 브라우저 URL, `.url`, 파일·폴더·exe·`.lnk`, Pack |
| 공지 | 홈 한 칸. 줄마다 기관(담당자) 또는 부서. 제목+날짜 3건. 모두에서 넣기·수정·빼기. Pack은 고른 항목만 추가(같은 id 건너뜀). 일정 동기화·게시판 수집 없음 |
| 할 일 | 홈에서 오늘·내일·모레에 넣을 수 있음. 처음 설치에는 비어 있음. 저장·백업은 YYYY-MM-DD. 화면은 오늘(9.20) 형식. 날짜 줄 오른쪽 캘린더로 구글·네이버 공식 누리집만 염. 일정 동기화·로그인 연동 없음 |
| 바탕화면 미니 창 | 설정에서 켬. 기본 끔. 작업 영역 왼쪽 아래 220×140 창. 오늘 날짜, 오늘·지난 미완료 건수, 런처 열기. 패널을 숨겨도 남음. 제목 줄 X는 그 창만 숨김. 홈을 연 뒤에 창을 만든다. 트레이 종료로 프로그램이 꺼짐. Windows 위젯 보드·바탕화면 아이콘 뒤 붙이기 아님 |
| 네트워크 | IPv4 구간 응답 확인, CCTV 추정 (이 PC에서만). 검색 중 예상·경과 시간, 중지 |
| 이 PC 인터넷 바로가기 | 사이트 칸에서 Edge·Chrome 로컬 Bookmarks 파일과 Windows `Favorites`의 `.url`만 목록으로 봄. 쿠키·방문 기록은 읽지 않음 |
| 컴퓨터도구 | 업무도구 칸에서 이 PC Windows 설정 화면(제어판·시스템 정보·익스플로러 설정 복원 확인 포함)을 열거나, 사설 IP 주소와 공인 IP 주소만 본다. 「이 PC 폴더 찾기」는 이 사용자 폴더의 이름만 찾는다. 원할 때만 런처에 추가 |
| 주소 무늬 | 업무도구. 이 PC PNG/JPEG 그림 오른쪽 아래에 http(s) 주소 무늬를 넣고 PNG로 저장. 원본은 그대로. 인터넷 생성기 없음 |
| 업무자료 | 홈 검색과 업무도구 칸에서 교육행정 업무주제(Topic)를 찾음. 로컬 JSON. 검색 결과 위에 같은 JSON으로 그린 업무 그림(자체 SVG). 크게 보기는 런처와 같은 높이로 옆을 조금 더 넓게 펼치고 그림을 창에 채움(패널과 같은 index.html, 제목 줄로 닫기). 단추·휠로 크기, 끌어서 이동. 상자 누르면 패널 상세. 칸 크기는 스크롤바와 나누어 잰다. 상세에서 위쪽 뒤로 또는 오른쪽 아래 이전화면을 누르면 직전 검색 화면이 다시 나옴. 처음 화면은 빈 홈. 업무지도 탭은 접이식 목록. `src/data/manuals/*.json`을 추가하면 검색·지도·상세에 붙음. 첫 매뉴얼은 EPKI 인증서. AI·NotebookLM 수집 없음. JSON에 주소가 있는 자료만 바깥에서 염. 처리 흐름은 상자 순서. 처음 화면 단추로 홈으로 돌아감. 최근 사용에는 열어 본 주제만 넣고 검색어는 넣지 않음 |
| 보기 | 설정에서 서류·밝은 화면·어두운 화면 스킨. 모두 목록 1열·2열. 패널 안 색만. 칸마다 색 고르기 없음 |
| 백업 | 설정 JSON 내보내기/가져오기. 파일 본체는 복사 안 함 |
| 이 PC 폴더 이름 | 홈 검색 맨 아래(최대 5건)와 컴퓨터도구 전용 화면. 바탕화면·문서·다운로드의 파일·폴더 **이름**만. 내용은 읽지 않음. 전용 화면에서 사진·음악·동영상도 선택. C:\ 전체·내용 색인·Everything/시작 메뉴 복제 없음 |
| 소개 사이트 | 설정 하단에서 웹 소개 주소를 열고, 설치 파일은 GitHub Releases |

## 화면

데스크톱: `src/` + `src-tauri/` (Tauri 패널, 라우터 없음)

웹 소개 (`website/`): `/` 소개, `/preview` 모양만, `/download` GitHub Releases

## 성공 기준

- 트레이만 남고 필요할 때만 패널
- Pack·끌어놓기로 목록을 나눌 수 있음
- 다른 PC는 백업 JSON으로 목록만 이어받음 (로컬 경로는 깨질 수 있음)
- 설치는 GitHub Releases의 NSIS, 소개 사이트는 Cloudflare
