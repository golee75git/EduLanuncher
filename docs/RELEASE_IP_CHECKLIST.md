# Release IP checklist

법적 비침해를 이 파일만으로 보장하지 않는다. 출시 전 전문가 검토를 권장한다.

- [ ] 제품명 상표 검색
- [ ] 도메인 확인
- [ ] 로고 독자 제작 여부 확인
- [ ] UI 모방 여부 확인
- [ ] 외부 코드 라이선스 확인
- [ ] npm 패키지 라이선스 확인
- [ ] Rust crate 라이선스 확인 (전이 의존성 포함)
- [ ] 아이콘 라이선스 확인
- [ ] 데이터 출처 확인
- [ ] THIRD_PARTY_NOTICES 업데이트
- [ ] GPL/AGPL 의존성 확인
- [ ] 기능별 특허 검토 대상 확인
- [ ] IP_REVIEW_REQUIRED 항목 확인
