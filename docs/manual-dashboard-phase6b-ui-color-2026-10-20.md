## 확인

로컬 화면에서 공문서 생산과 물품구매 시범에 파랑·보라·분홍 박스가 있고, 공문서 단계 문구는 그대로였다.

웹사이트만 배포했다. Worker `924ae9aa-a706-40a5-9d9e-febd6feff59f`. 스크립트 `index-BPwOhZfa.js`, 스타일 `index-C8an84Rh.css`. 업무자료 해시는 이전과 같다. `npm run deploy`는 실행하지 않았다. 되돌릴 이전 버전은 `7879f51b-e6df-466f-9207-b3a269185d41`이다.

확인하지 않은 것: 인쇄 대화상자, 좁은 화면을 손으로 넘기기, 체크를 저장한 뒤 새로고침, 키보드로 아코디언을 여닫기. 인쇄용 스타일은 테두리를 남기고 배경색 인쇄를 요청하도록만 넣었다. 브라우저 설정에 따라 배경이 빠질 수 있다.

글꼴은 시스템 글꼴이다. OFL 파일을 추가하지 않았다. 새 패키지는 없다.
