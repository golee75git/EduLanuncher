# 날짜·버전 정리

기준일: 2026-11-28  
현재 설치 버전: `0.1.259-20261128`

이 앱은 Windows용 NSIS 설치 파일이다. APK와 Play 스토어 버전은 없다. 이번 문서는 이미 있는 기록을 가리킨다.

## 어디를 보나

| 보고 싶은 것 | 파일 |
|---|---|
| 지금 동작 | `docs/PRD.md` |
| 날짜별 넣은 것 | `docs/PLAN.md`. 최신 날짜가 위다. 같은 날짜에서는 위 항목이 최신이다 |
| 이어 작업 | `docs/HANDOFF.md` |
| 버전별 한 줄 | `website/src/data/releases.ts`. 소개 페이지와 같다 |
| 요청자 기록 | `수정기록.txt` |

버전별 한 줄을 여기에 다시 적지 않는다. 날짜별 묶음을 여기에 다시 적지 않는다.

## 같은 날 나중에 덮인 설명

- 바로가기 점: `0.1.220-20261122`는 세로 점, `0.1.221-20261122`는 마지막 아이콘 위 가로 점, `0.1.229-20261122`는 업무도구 오른쪽 세로 점이다. 업무도구가 없으면 마지막 아이콘 오른쪽이다.
- 업그레이드 받기: `0.1.210-20261120`은 브라우저로 받는다. `0.1.228-20261122`부터 이미 설치된 런처는 설치 폴더에 받아 설치 창을 연다. 처음 설치는 브라우저 그대로다.

## 이번 정리에서 하지 않은 것

- 이 색인에 수정 문장을 다시 적지 않음. 날짜별 내용은 PLAN, 버전별 한 줄은 releases를 본다
- 직접 의존성에 GPL을 추가하지 않음. 라이선스 준수를 보장하지 않음
- 검증된 특허 청구항 원문은 보지 않음. 문서 색인이라 새 기술 구성은 없음. 특허 비침해를 보장하지 않으며 법적 검토가 아님
